# Slopium

Клиентский мод для **Minecraft 1.21.1 / NeoForge 21.1.242 / Java 21**, версия **0.1.0-alpha.10**. Оптимизации освещения, частиц и визуальной нагрузки Create. Требуется Sodium 0.8.13 для 1.21.1; меню Reese’s Sodium Options поддерживается.

**Установка:** заменить предыдущий Slopium в клиентской папке mods на `build/libs/slopium-neoforge-1.21.1-0.1.0-alpha.10.jar`, перезапустить игру. Серверная установка не нужна. Существующий `config/slopium.json` сохраняется; сбрасывать настройки после обновления не требуется.

## Настройки

Настройки графики → Slopium. В alpha.10 меню организовано по объектам, а не по поколениям экспериментов. Каждый параметр расположен один раз.

| Раздел | Что здесь находится |
|---|---|
| Общее и свет | Общий выключатель, диагностика, трещины, Xaero, оптимизации света и источники Create/Sable |
| Частицы | Скрытие за препятствиями и за радиусом, кеш света, ограничение новых частиц |
| Create: модели и анимации | Скрытие обычных моделей и моделей Flywheel, пауза скрытых анимаций, дальние обновления |
| Create: фабричные панели | Радиусы предметов и лампочек, выбор видимости соединений |
| Create: клиентские обновления | Один способ разрежения тиков и только его применимые параметры |
| Предметы и детали мира | Выпавшие предметы, специальные модели блоков, тени, смешивание кадров текстур |
| Диагностика: отключения | Полные отключения для измерений; перекрывают соответствующие обычные настройки |

**Скрывать за препятствиями:** «Выключено» / «За непрозрачными блоками» / «За любыми блоками». Отдельный тумблер больше не нужен. Для частиц в окне выбрать последний вариант; стекло считается препятствием. Неприменимые радиусы и интервалы недоступны; подсказки объясняют зависимость и приоритет полного отключения.

Три прежних способа редких тиков объединены в один выбор. При открытии старой конфигурации показывается фактически приоритетный способ, а выбор нового выключает конкурирующие флаги. EntityCulling доступен как способ только при наличии этого мода. Параметры за препятствиями и за радиусом имеют отдельные подписи.

## Alpha.10

Исправлен воспроизведённый случай частиц сразу за стеклянной панелью: расширенная область фрустума больше не используется для проверки препятствий и не исключает соседнее стекло. Проверяется интерполированный центр частицы. Проверки частиц имеют собственный бюджет и очередь, независимые от Create. При нехватке бюджета результат откладывается, неподтверждённые частицы остаются видимыми.

Это приближённое отсечение целой частицы по её центру: на краях препятствий возможны резкие переходы. Собственные системы частиц модов вне стандартного ParticleEngine не охвачены. Рендер Create охватывает специальные модели и проверенные визуализации Flywheel, а не всю геометрию чанков. Sable-позиции защищены. Серверная симуляция и сетевой протокол не меняются; разрежение клиентских тиков может замедлять звуки, анимации и индикаторы.

[Настройки, тесты и ограничения alpha.10](docs/ALPHA10_TESTS.ru.md). [Журнал проверок](docs/VALIDATION.ru.md).

## Измерения

Включить сбор статистики, выполнить `/slopium reset`, закрыть меню и чат, провести 60–90 секунд в одной сцене, затем `/slopium status`. Сравнивать время кадров и FPS при неизменных позиции, направлении камеры и нагрузке. Строка `Particle visibility` показывает число проверок, скрытий, отложенных запросов и исключений Sable. Счётчики сами по себе не доказывают ускорение.

После применения настроек перестраивается клиентская геометрия и сбрасывается замер кадров: перед сравнением дождаться стабилизации. Полные диагностические отключения нужно выключить при проверке обычных оптимизаций. Distant Horizons и F3 не изменяются.

**60 FPS в заводской сцене и 400 FPS вне заводов не подтверждены.** Для alpha.10 пользовательский FPS ещё не измерен. Предыдущие пользовательские результаты и анализ находятся в `analysis/`.

## Сборка и история

`gradlew.bat build` собирает мод и запускает unit-тесты. Изолированные клиенты: `runSmokeClient -PwithReferenceMods` (full), с `-PsmokeProfile=legacy` (Create без Sable/EntityCulling, старый Create Dynamic Light), с `-PsmokeProfile=minimal` (без Create). Smoke-код не входит в JAR. Эталонные моды используются из `reference/mods` и не встраиваются в Slopium.
