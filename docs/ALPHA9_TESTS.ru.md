# Slopium alpha.9

Иконка повторно скопирована из актуального reference/logoT.png без изменения картинки — в метаданные NeoForge и текстуру меню Sodium/Reese.

## Фабричные панели

На странице «Панели, частицы и тики» добавлен отдельный переключатель радиуса предметов и ползунок «Полная отрисовка предметов». Внутри радиуса рендер обычный, снаружи FilteringRenderer для FactoryPanel пропускается целиком. Это скрытие дальних предметов, не замена их плоскими изображениями. Остальные фильтры Create не затрагиваются, ItemStack и серверное состояние не меняются.

Радиус индикаторов оставлен отдельным: «Полная отрисовка индикаторов». За ним не рисуются лампы и свечение. Прежний скрытый запас +2 блока убран; оба радиуса измеряются от центра панели до камеры и ограничены дальностью чанков. Наведение на панель, открытое меню, виртуальные миры и Sable сохраняют обычный рендер. Клиентские тики индикаторов продолжаются: эта настройка исключает отрисовку, а не логическое обновление.

Начать можно с 16 блоков для предметов и 24 для индикаторов, проверяя переключатели по одному. Счётчик factory items — число пропущенных проходов FilteringRenderer, не число отдельных предметов. factory bulbs — пропуски renderBulb.

## Препятствия для куллинга

На странице «Куллинг за стенами» теперь пять независимых выборов: для частиц, обычного рендера Create, Flywheel, анимаций и редких тиков. Каждый предлагает:

- **Непрозрачные** — блоки, объявленные игрой пригодными для непрозрачного отсечения; учитывается их форма.
- **Любые блоки** — также прозрачные и неполные блоки: стекло, стеклянные панели, двери, решётки, растения и жидкости. Луч должен пересечь форму блока/жидкости; пустое место внутри блока не закрашивается условным полным кубом.

Выбор препятствий сам по себе не включает куллинг — основной переключатель остаётся отдельным. Настройки Flywheel и анимаций действительно независимы, включая общий визуальный объект. Для тиков и обычного BER тоже передаётся собственный выбор.

Старый режим стекла проверял только полные кубы коллизии. Поэтому стеклянные панели и прочие тонкие формы пропускались. В alpha.9 используется пересечение с outline shape, а не требование полной коллизии. Области кеша округляются наружу до 0.25 блока вместо 2 блоков: меньше лишнего расширения возле тонких препятствий, но меньше повторного использования кеша. Ограничения по числу лучей, обходу блоков и времени сохранены. При нехватке бюджета объект остаётся видимым.

Старый JSON-флаг opaqueGlassParticles сохранён для совместимости: true теперь означает «Любые блоки» для частиц. Остальные новые выборы по умолчанию — «Непрозрачные». Модовые outline shapes и признаки непрозрачности могут не совпадать с картинкой текстуры; это не анализ пиксельной прозрачности моделей. Открытая дверь и отверстия между решётками не должны перекрываться там, где форма отсутствует. Невидимые блоки без формы не становятся препятствием.

## Проверка в мире

Полные отключения частиц/BER/Flywheel и полную заморозку Create выключить, чтобы они не перекрывали новые режимы. Включить нужный куллинг и сравнить оба типа препятствий с одной точки перед стеклом/панелями. После разрушения преграды и при выключении режима объекты должны возвращаться.

Для панелей сравнить радиус предметов и индикаторов отдельно от линий. Диагностика: /slopium reset, затем 60–90 секунд с закрытым чатом, /slopium status. Оценивать avg/p95/p99, а не только счётчики.

Прежние ограничения сохраняются: девять лучей — приближённая проверка, узкие отверстия могут давать ошибочное отсечение; охвачены не все визуализации Flywheel; Sable исключён; редкие тики могут замедлять клиентские эффекты. Серверная симуляция не меняется. Прирост FPS в пользовательском мире не измерен.
