# Бета 3: ограничение входных FPS

Дата: 28 октября 2026. Настройка `frameGenerationInputFps`, диапазон 0–240, по умолчанию 0. Один параметр для обоих методов. Ограничивается настоящая отрисовка мира; выход дополнительно ограничен произведением входного предела и множителя. Меньшие ограничения вывода сохраняются.

## Проверки

- 28 unit-тестов без ошибок, включая частоты 1/30/60/75/120/240, отключение, смену предела, сброс, задержки и отсутствие догоняющих захватов.
- `build/beta3-legacy.log`: изолированный клиент, оба GPU-алгоритма, множители ×2/×3/×4/×8/×32, ограничение входа.
- `build/beta3-full.log`: финальный код, полный набор модов, 59 настроек, обе реализации генерации, быстрые повороты камеры при входном пределе, OpenGL-состояние, выход и пауза. BUILD SUCCESSFUL.
- `build/beta3-input-world.log`: настоящий игровой цикл в отдельно созданном мире, по 8 секунд на режим. При входе 30 и ×2: простая генерация 239 настоящих кадров, средний выход 59,89 FPS; FSR 229 настоящих кадров, средний выход 57,40 FPS. При входе 120 и ×4: простая 842 настоящих кадра, выход 422,31 FPS; FSR 838 настоящих кадров, выход 419,14 FPS. Все верхние пределы соблюдены. Этот запуск предшествует финальной защите от обхода лимита резкими поворотами; защита отдельно проверена финальным full-запуском.
- Скриншот `run/smoke-full/screenshots/slopium-beta3-page-1.png`: новая настройка в разделе генерации, правильная русская подпись, версия «Бета 3»; просмотрен визуально.

Minecraft обычно не ограничивает вывод при значении от 260 FPS. Проверено изменение соответствующего условия: конечный потолок, например 120 ×4 = 480, теперь действительно применяется. При выключенной генерации прежнее поведение остаётся.

## Ограничения измерений

Это проверка ограничения и функциональности, не сравнение производительности заводов пользователя. Тестовый мир мал, короткие последовательные прогоны не позволяют утверждать прирост FPS. Счётчик `base` использует последнее окно измерения и может отличаться от среднего за весь прогон. FSR может удерживать готовый кадр до следующего разрешённого входа; это отдельно учитывается как `held`. При низком входном FPS и резком повороте старое изображение удерживается до следующего разрешённого захвата. Первый кадр после сброса истории выполняется сразу.

Пользовательские mods и config не изменены. Артефакты и контрольные суммы: `analysis/slopium-beta3-build.json`.
