# Бета 10: числовой ввод, FPS и независимая генерация

2 ноября 2026.

## Причины и исправления

Reese 2.2.4 использует `IntegerSliderOptionRow`, а прежний обработчик находился только в `Sodium SliderControlElement`. Поэтому отдельный тест слайдера проходил, а пользовательский клик не достигал обработчика. Добавлена интеграция с реальной строкой Reese. Правый клик и Shift + левый клик открывают числовое поле только для активных числовых настроек Slopium. Проверка теперь начинает клик от настоящего экрана и проходит дерево его элементов.

Прежние «настоящие FPS» параллельного режима вычислялись по опубликованным/пропущенным снимкам за всё время сессии. Последовательный счётчик также усреднялся по длительному замеру. Ванильный F3 при этом считал основной цикл, который может включать генерацию и повтор изображения, а при параллельном выводе не учитывает поток генератора.

Новый общий замер:

- Настоящие: один успешно выполненный проход отрисовки мира за кадр Minecraft. Синтетический и сокращённый проходы не учитываются. Пропуск снимка в очереди не уменьшает число исходных отрисовок.
- Вывод: возврат из обычного `glfwSwapBuffers` или успешный `SwapBuffers` параллельного потока. Повторённые изображения входят в вывод; это не число уникальных изображений и не физическая развёртка монитора.
- «Создано»: синтетический кадр считается только после вывода. Технические счётчики подготовленных изображений остаются отдельно в status.
- Частота обновляется по недавним интервалам около секунды. Длительная остановка даёт нулевую частоту; первый замер требует прогрева. Меню и паузы не смешиваются с новой выборкой после возврата.
- F3 и оверлей используют один снимок значений на кадр. Обновление строки перед отрисовкой также обходит устаревший текстовый кеш Sodium Extra, сохраняя кеш остальных данных. Ванильные `Minecraft.getFps()` и графики времени потока не подменяются: сторонние измерители могут считать иные события. HUD параллельного генератора по-прежнему обновляется с исходными кадрами.

В счётчиках нет блокировок между потоками: каждый поток обновляет собственный счётчик, чтение идёт из опубликованной выборки. Сброс меняет банк счётчиков вместо одновременного изменения накопителей.

Удалены зависимости генерации от `enabled` в меню, обычном/сокращённом рендере и параллельном выводе. `enabled` переименован в «Включить оптимизации Slopium». Отдельное выключение генерации — режим OFF; прежняя конфигурация читается без миграции.

## Проверки

Модульные проверки нового счётчика сравнивают 30 исходных / 60 выводимых FPS, переход на 2 FPS после долгой быстрой работы и отсутствие событий. Старые проверки генерации и планировщика сохраняются.

`build/beta10-ui-retry.log`: настоящий экран Reese → правый клик по строке Target FPS → ввод 2 → Enter → исходный экран с несохранённым значением. Проверены зависимости меню при выключенных оптимизациях. Последовательные Simple/FSR и их адаптивные режимы проверены при `enabled=false`.

`build/beta10-ui-plain-retry.log`: тот же маршрут через настоящий экран Sodium без Reese прошёл; опциональный миксин Reese не мешает запуску без этого мода. Повторно прошли GPU/lifecycle-проверки последовательных Simple/FSR при `enabled=false`, сохранены снимки всех страниц. Первый plain-тест использовал координату колонки Reese, отсутствующую в более узкой колонке Sodium, и остановился до клика. Исправлен только поиск видимой точки строки в тесте; реализация обычного слайдера изменений не потребовала.

Первый запуск (`build/beta10-ui.log`) остановился в загрузчике NeoForge с `FileSystemNotFoundException` до открытия игрового окна; повторный запуск прошёл. Пользовательские mods/config не изменялись.

`build/beta10-fps-world.log`: полный набор reference/mods, настоящий мир, параллельный FSR с выключенными оптимизациями. Независимый замер за фазу: 13.07 исходных / 59.26 выводимых FPS; последняя секундная выборка: 13.87 / 60.03. При задержке игрового потока на секунду: 0.966 / 60.00 за фазу и 0.973 / 59.99 в счётчике. Разница между последней секундой и всей фазой ожидаема. Проверено совпадение F3 с общей выборкой, отделение HUD, остановка синтеза после восстановления исходной частоты, меню, изменение размера, VSync и смена Simple/FSR. Начало теста задержал диалог обновления Xaero; после отказа от обновления тест завершился успешно. Эти числа подтверждают корректность измерения на тестовой сцене, а не производительность на пользовательском сервере.

`build/beta10-final-parallel.log`: финальный код, полный набор модов с Sodium Extra, простая параллельная генерация и выключенные оптимизации. За фазу получено 14.31 / 59.82 FPS, при секундной задержке — 0.975 / 60.07. Проверены общая выборка F3/HUD, обновление устаревшей строки без изменения других строк кеша, отделение HUD, восстановление частоты и весь жизненный цикл вывода. BUILD SUCCESSFUL. Уведомления Xaero отключены только в изолированной тестовой конфигурации.

Итог: 44 модульных теста, 0 ошибок; успешные запуски интерфейса с Reese и без него, последовательных Simple/FSR и параллельных Simple/FSR. Состав JAR, отсутствие тестового кода, паритет переводов и SHA-256 проверяются `build/beta10_manifest.py`; результат — `analysis/slopium-beta10-build.json`.
