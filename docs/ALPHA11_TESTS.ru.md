# Alpha.11: Create за окном и полные режимы в меню

## Что исправлено

В alpha.10 обычные модели Create проверялись по увеличенному render bounding box. Блоки, пересекавшие эту область, исключались как часть механизма: соседнее окно могло вообще не попасть в проверку. Кроме того, точный список классов Flywheel не включал LargeCogVisual, поэтому большая шестерня обходила скрытие, хотя её базовый SingleAxisRotatingVisual поддерживался.

В alpha.11 проверяется центр блока механизма, исключается только его собственная ячейка. Большая шестерня скрывается вместе с дополнительным валом. Добавлены OrientedRotatingVisual, LargeCogVisual, EncasedCogVisual, GearboxVisual, FanVisual и SplitShaftVisual; всего 11 проверенных классов. Их методы collectCrumblingInstances проверены по бинарникам Create 6.0.11: они перечисляют принадлежащие визуализации фиксированные экземпляры. Неизвестные типы автоматически не подключаются.

CreateOcclusion имеет отдельный от частиц бюджет: 1024 луча, 32768 шагов и примерно 1 мс накопленного времени трассировки за кадр. Один луч может превысить оставшееся время. Кеш до 16384 записей по блоку и режиму препятствий, срок до 20 кадров; очередь до 4096 отложенных запросов обслуживается перед новыми. Движение камеры, изменение блоков/настроек и смена мира сбрасывают кеш. Дальность проверки — 128 блоков. Нехватка бюджета, непрогруженные чанки и Sable дают видимый результат, а не доказательство скрытости.

**Это агрессивное отсечение по центру.** У края окна часть модели может быть видима, но вся специальная модель скроется. Статические корпуса и другие блоки, вошедшие в геометрию чанков, остаются. Открытые промежутки между формами блоков не считаются сплошной стеной. Модель под прицелом и модели при открытом меню защищены от обычного отсечения. Полное скрытие — отдельный режим без такой проверки.

## Пауза анимаций

Вращение кинетических деталей выполняет shader Flywheel; отмена Java beginFrame его не останавливала. Теперь поддерживаемые RotatingInstance сохраняют визуальный угол на момент паузы. Реальный writer AllInstanceTypes.ROTATING отправляет нулевую скорость и сохранённый угол, не изменяя поля скорости/смещения Create. При возвращении видимости/выключении режима помечается новое обновление данных и используется актуальное состояние механизма. Серверная симуляция не меняется.

Кадровые обновления пресса, миксера и воронки также приостанавливаются. Поддерживаются режимы за непрозрачными, за любыми препятствиями и везде. Не охвачены все визуализации Create, подвижные конструкции Sable и обычный кинетический рендер при неактивном backend Flywheel. Полная пауза относится к поддержанным визуализациям, а не ко всем анимациям игры.

Пауза вращения сама по себе не убирает вызовы рисования и работу вершинного шейдера, поэтому не обещает увеличения FPS. Для сокращения отрисовки предназначено скрытие моделей.

## Меню

Шесть разделов и 46 параметров. Страница «Диагностика: отключения» удалена; общий сбор статистики остался в «Общее и свет».

| Настройка | Новое полное значение |
|---|---|
| Частицы → Скрывать частицы за препятствиями | Скрыть все |
| Create: модели и анимации → Скрывать обычные модели Create | Скрыть все — только обычные BlockEntityRenderer Create |
| Create: модели и анимации → Скрывать модели Flywheel | Скрыть все — весь Flywheel, включая другие моды |
| Create: модели и анимации → Приостанавливать анимации Create | Приостановить везде — поддержанные визуализации |
| Create: клиентские обновления → Реже обновлять механизмы на клиенте | Заморозить все клиентские тики |
| Предметы и детали мира → Специальные модели блоков | Показывать все / Только в радиусе / Скрыть все — обычные BlockEntityRenderer всех модов |

Отключение фоновых эффектов перенесено в «Предметы и детали мира». Старые полные флаги конфигурации остаются читаемыми и отображаются новыми значениями. Выбор обычного режима снимает полное отключение этой функции. Зависимые радиусы и интервалы серые при полном отключении; сам переключатель остаётся доступен, чтобы можно было вернуться назад. Подсказки указывают область действия и приоритеты.

## Проверка в пользовательской сцене

1. Заменить старый JAR на alpha.11 и перезапустить игру. Конфигурацию удалять не нужно.
2. В «Create: модели и анимации» выбрать для обычных моделей и Flywheel «За любыми блоками». Закрыть меню. Сравнить видимые вращающиеся детали за окном с режимами «Выключено» и «За непрозрачными блоками».
3. Снять стекло/выйти из-за стены: детали должны вернуться. Статические корпуса могут оставаться видимыми во всех режимах.
4. Для паузы выбрать «Приостанавливать анимации Create → Приостановить везде», оставив скрытие моделей выключенным. Поддержанные вращающиеся детали должны остановиться, а после отмены — продолжить с актуальным состоянием.
5. Для полного визуального отключения специальных частей выбрать «Скрыть все» в обоих путях моделей; это не отключает серверные механизмы и не удаляет статические блоки мира.

В `/slopium status` добавлена строка `Create visibility`: запросы, отложенные проверки и исключения Sable. Скрытые экземпляры учитываются в `Walls → Flywheel instances`. Это счётчики, не измерение выигранного времени. Замер FPS пользовательской серверной сцены в alpha.11 не выполнен.
